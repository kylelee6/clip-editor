# In·Out 클립 편집기

휴대폰 브라우저에서 동영상을 **구간 자르기 · ROI 크롭 · 화질 개선 · 슬로우 모션(AI 보간)** 하는 웹앱입니다.
설정을 모두 정한 뒤 **한 번의 인코딩**으로 MP4를 만듭니다. 영상은 폰 밖으로 나가지 않습니다.

**바로 쓰기: https://kylelee6.github.io/clip-editor/**

## 기능

| 기능 | 내용 |
|---|---|
| 구간 자르기 | IN/OUT 마커, 프레임 단위(±1f) 조정. 항상 재인코딩해서 키프레임과 무관하게 정확히 자름 |
| ROI 크롭 | 자유 / 1:1 / 9:16 / 16:9 / 4:5 박스. 출력 크기는 짝수 픽셀로 맞춤 |
| 화질 개선 | 언샤프 마스크 + 약한 대비·채도 보정(약/보통/강), 2배 업스케일 옵션 |
| 슬로우 모션 | 0.5× / 0.25×. 중간 프레임 생성: 복제 · 블렌딩 · 모션 보간 · **AI 보간(RIFE)** |
| 저장 | MP4(H.264, 안 되면 HEVC). 슬로우 모션이 아니면 소리 유지 |

모든 처리는 `디코딩 → 크롭 → 화질 개선 → 프레임 보간 → 인코딩` 한 번으로 이어지므로, 여러 번 저장할 때처럼 화질이 누적해서 떨어지지 않습니다.

## 사용법

1. 폰 크롬에서 위 주소를 열고, 메뉴에서 **앱 설치**(또는 홈 화면에 추가)를 누릅니다.
2. **동영상 열기** → IN/OUT 지정 → 필요하면 ROI·화질·슬로우 모션 선택.
3. **내보내기**(폰 안에서 변환) → 결과 미리보기 → **파일 받기**(폰의 다운로드 폴더에 저장, 갤러리에서도 보임).

AI 보간을 처음 쓸 때 모델과 실행 파일(약 50MB)을 한 번 받습니다. 와이파이에서 **오프라인용 AI 미리 받기**를 눌러 두는 것을 권장합니다.

## 개인정보 · 오프라인

- 영상은 브라우저 안에서만 처리됩니다. 앱에는 영상을 서버로 보내는 코드가 없습니다.
  외부 주소는 앱 파일을 **받기만** 하는 GitHub Pages, cdn.jsdelivr.net(라이브러리), Google Fonts뿐입니다.
- 서비스 워커(`sw.js`)가 한 번 받은 파일을 모두 폰에 저장하므로, 이후에는 **비행기 모드에서도** 앱이 열리고 AI까지 동작합니다.
  (Korean 글꼴 일부는 오프라인에서 기본 글꼴로 대체될 수 있습니다.)

## AI 보간 속도

- AI는 폰 GPU(WebGPU)를 먼저 시도하고, 안 되면 CPU(멀티코어 WASM)로 처리합니다.
  AI 보간을 고르면 어느 장치를 쓰는지, GPU를 못 쓰면 그 이유가 표시되고, 완료 후 프레임당 처리 시간이 표시됩니다.
- WebGPU 조건: Android 12 이상, 크롬 121 이상, 크롬이 차단하지 않은 GPU 드라이버.
  차단된 경우 `chrome://flags`의 **Unsafe WebGPU Support**로 강제할 수 있지만 불안정할 수 있습니다.
- **AI 고속 모드**(기본 켜짐)는 움직임을 절반 해상도로 계산해 약 3배 빠릅니다.
- 참고 측정(PC CPU 4스레드, 640×360): 정밀 약 170ms/프레임, 고속 약 51ms/프레임. 폰은 이보다 느립니다.
  픽셀 수에 비례하므로 **ROI를 작게 크롭하면 빨라집니다.**

## 한계

- 모션 보간(비 AI)은 한 프레임에 화면 폭의 약 7% 이상 움직이는 물체를 놓치고 그 부분은 블렌딩으로 처리됩니다. 이럴 때는 AI 보간을 쓰세요.
- 결과 영상은 메모리에 만든 뒤 저장하므로 아주 긴 4K 영상은 폰에서 버거울 수 있습니다.
- 슬로우 모션 결과에는 소리가 들어가지 않습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체(UI, 편집, WebGL 처리, AI 연동) |
| `sw.js` | 오프라인 캐시 + 멀티스레드용 COOP/COEP 헤더 추가 |
| `manifest.webmanifest`, `icon-*.png` | 앱 설치 정보 |
| `rife426.onnx` | RIFE v4.26 AI 보간 모델(정밀) |
| `rife426_fast.onnx` | 같은 모델의 고속 버전(움직임을 절반 해상도로 계산) |
| `tools/export_rife.py` | 위 두 ONNX 파일을 공식 가중치로부터 다시 만드는 스크립트 |

## 기술 구성

- 영상 디코딩·인코딩: [Mediabunny](https://mediabunny.dev) (WebCodecs, 폰 하드웨어 코덱 사용)
- 크롭·화질 개선·블렌딩·모션 보간: WebGL2 셰이더 (모션 보간은 3단 피라미드의 양방향 블록 매칭)
- AI 보간: [RIFE](https://github.com/hzwer/Practical-RIFE) v4.26 → ONNX, [onnxruntime-web](https://onnxruntime.ai) (WebGPU / WASM)

### 모델 다시 만들기

```bash
python tools/export_rife.py   # torch, onnx 필요. 공식 가중치를 받아 rife426*.onnx를 다시 씀
```
